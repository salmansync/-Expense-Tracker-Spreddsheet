## 📖 System Overview
This tracker is designed to provide financial clarity through automated data aggregation. It eliminates the guesswork in personal budgeting by bridging the gap between daily micro-transactions and long-term asset growth.

### Core Capabilities:
* **Strategic Dashboard:** Automated summary of Total Net Worth vs. Total Expenses.
* **Categorized Revenue:** Tracking for Salary, Digital Wallets (Bkash), and Passive Income (Rent).
* **Asset Allocation:** Real-time visibility into Cash, Bank Balances, and Investments (Sanchaypatra/Stocks).
* **Visual Intelligence:** Dynamic charting for income distribution and asset liquidity.

## 🛠️ Implementation Guide

### 1. Initialization
1. Open the [Google Sheets Template](https://docs.google.com/spreadsheets/d/1H95vbSsGP-7GVE4TaheP3GpgJOF1dsN3CCHCsJHezKc/edit?usp=sharing).
2. Navigate to `File > Make a copy` to link it to your personal Google Drive.
3. Update the **ACCOUNTS (ASSETS)** table with your current opening balances.

### 2. Operational Workflow
* **Income Entry:** Record revenue in the main dashboard under the respective monthly column.
* **Expense Logging:** Use the monthly tabs (e.g., February 2026) to log daily spending.
* **Review:** The system utilizes the following logic for valuation:
  $$\text{Total Net Worth} = \sum(\text{Liquid Assets} + \text{Investments}) - \sum(\text{Liabilities})$$
